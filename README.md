# Трекер расходов (MBank · O!Bank · Simbank → Google Sheets)

Каждая оплата через **Apple Pay** на iPhone автоматически попадает в Google-таблицу
с категорией. Сводка показывает, на что уходят деньги в этом месяце.

```
Оплата Apple Pay ──► Команды iOS (автоматизация «Транзакция»)
                         │  POST {сумма, магазин, карта}
                         ▼
                 Google Apps Script (веб-приложение)
                         │  разбор суммы, чистка названия, категория по правилам
                         ▼
                 Google Sheets: «Транзакции» · «Правила» · «Сводка» (+ диаграмма)
```

Сервер не нужен, всё бесплатно, данные лежат только в твоём Google Drive.

---

## 1. Google-таблица и скрипт (≈5 минут)

1. Создай новую таблицу на [sheets.new](https://sheets.new), например «Расходы».
2. **Расширения → Apps Script**. Удали всё в `Code.gs` и вставь содержимое
   [`apps-script/Code.gs`](apps-script/Code.gs). Сохрани (💾).
3. В списке функций сверху выбери **`setup`** → **Выполнить**. Разреши доступ
   (Google предупредит, что приложение «не проверено»: *Дополнительно → Перейти…*).
4. Открой **Журнал выполнения** и скопируй **токен** из строки
   `Готово. Токен для Команды на iPhone: …`
   (потом его можно посмотреть в таблице: меню **Расходы → Показать токен**).
5. **Развертывание → Новое развертывание** → тип **Веб-приложение**:
   - *Выполнять от имени:* **Я**
   - *У кого есть доступ:* **Все**

   Нажми **Развернуть** и скопируй **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).

> Если позже меняешь код, выбери **Развертывание → Управление развертываниями → ✏️ → Версия: новая**,
> тогда URL останется прежним.

## 2. Автоматизация на iPhone (≈3 минуты)

**Команды → Автоматизация → «+» → «Транзакция»**

1. **Карты:** отметь карты MBank, O!Bank, Simbank (все, что есть в Wallet).
2. Остальное (категории продавцов и т. п.) оставь как есть.
3. Выбери **«Запускать немедленно»** и выключи «Уведомлять о запуске», если не нужно. → **Далее**.
4. **Новая пустая команда**, добавь действие **«Получить содержимое URL»**:
   - URL: *URL веб-приложения из шага 1.5*
   - Нажми **›** → **Метод:** `POST`, **Тело запроса:** `JSON`
   - Добавь поля (тип **Текст**):

     | Ключ       | Значение                                                  |
     |------------|-----------------------------------------------------------|
     | `token`    | *токен из шага 1.4*                                       |
     | `amount`   | переменная **Входные данные команды → Сумма**             |
     | `merchant` | переменная **Входные данные команды → Продавец**          |
     | `card`     | переменная **Входные данные команды → Карта или пропуск** |

     (Нажми на поле значения → «Выбрать переменную» → **Входные данные команды**,
     затем ещё раз нажми на неё и выбери нужное свойство. В разных версиях iOS
     названия свойств могут немного отличаться, например *Amount / Merchant / Card or Pass*.)
5. *(По желанию)* добавь **«Получить значение словаря»** → ключ `message` из
   «Содержимое URL» и **«Показать уведомление»** с этим значением. После каждой оплаты
   будет всплывать `160 KGS · Apteka Elbrus → Здоровье`.

Готово. Заплати любой картой через Apple Pay, и через пару секунд в листе «Транзакции» появится строка.

## 3. Ручной ввод: QR-оплаты, переводы, наличные

Автоматизация «Транзакция» ловит **только оплаты Apple Pay** (приложил телефон или часы к терминалу).
Она не видит:
- оплату по **QR** внутри приложений MBank / O!Bank / Simbank;
- **переводы** по номеру телефона;
- оплату физической картой и наличными.

Для этого сделай отдельную команду **«Расход»** и вынеси её на экран «Домой»
(или на Back Tap / кнопку действия):

1. **«Запросить ввод»** → тип *Число*, вопрос «Сумма?»
2. **«Запросить ввод»** → тип *Текст*, вопрос «Где / на что?»
3. **«Выбрать из меню»** с категориями (Продукты, Кафе и еда, Такси, …) *(можно пропустить,
   тогда категорию определят правила)*
4. **«Получить содержимое URL»**, как выше, но поля:
   `token`, `amount` = *Ввод 1*, `merchant` = *Ввод 2*, `category` = *Выбранный пункт*, `source` = `manual`.

## 4. Таблица

| Лист | Что там |
|------|---------|
| **Сводка** | траты этого месяца по категориям (+ круговая диаграмма), топ-15 магазинов, итоги по месяцам, сумма за месяц |
| **Транзакции** | все операции. Категорию можно исправить руками прямо в ячейке |
| **Правила** | «если в названии магазина есть *X* → категория *Y*». Первое совпадение побеждает |

Меню **Расходы** в таблице:
- **Пересчитать «Без категории» по правилам.** Добавил новое правило, нажал, и старые операции разнеслись.
- **Пересчитать ВСЕ категории.** Переразмечает всё заново (ручные правки тоже перезапишутся).
- **Пересобрать сводку.**

Смотреть с телефона удобно в приложении Google Sheets: лист «Сводка».

## Формат запроса (для отладки)

```bash
curl -L -X POST 'https://script.google.com/macros/s/…/exec' \
  -H 'Content-Type: application/json' \
  -d '{"token":"…","amount":"KGS 160,00","merchant":"Apteka Elbrus  Bishkek, Bishkek","card":"MBank"}'
```

| Поле | Обяз. | Пример | Примечание |
|------|-------|--------|------------|
| `token` | да | `a1b2…` | из `setup()` |
| `amount` | да | `KGS 160,00`, `3 141,1 KGS`, `160` | понимает пробелы, запятые, коды валют |
| `merchant` | нет | `Globus Express  Bishkek, Bishkek` | город в конце и префикс `MD00` обрезаются |
| `card` | нет | `MBank` | |
| `currency` | нет | `USD` | по умолчанию из `amount`, иначе `KGS` |
| `category` | нет | `Такси` | если не передано, берётся из правил |
| `source` | нет | `manual` | по умолчанию `apple-pay` |
| `date` | нет | `2026-09-28T16:38:00+06:00` | по умолчанию время получения |

Повтор той же суммы в том же магазине в пределах 2 минут считается дублем и не записывается.

## Что можно добавить дальше

- **Импорт PDF-выписок** MBank / O!Bank / Simbank раз в месяц, чтобы подтянуть QR-оплаты и переводы,
  которые не прошли через Apple Pay, и сверить итог.
- **Авто-категоризация через LLM** для магазинов, которых нет в правилах, с запоминанием ответа как нового правила.
- **Telegram-бот:** пересылаешь скрин чека или перевода, он распознаёт и записывает.
- Бюджеты по категориям и уведомление, когда лимит почти исчерпан.
