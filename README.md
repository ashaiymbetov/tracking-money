# Трекер расходов (MBank · O!Bank · Simbank → Google Sheets)

Каждая оплата через **Apple Pay** на iPhone автоматически попадает в Google-таблицу
с категорией. QR-оплаты и переводы добавляются двойным тапом по крышке iPhone: скрин чека
распознаёт Claude. Сводка показывает, на что уходят деньги в этом месяце.

```
Оплата Apple Pay ──► Команды iOS (автоматизация «Транзакция»)
                         │  POST {сумма, магазин, карта}
                         ▼
                 Google Apps Script (веб-приложение)
                         │  разбор суммы, чистка названия, категория по правилам
                         ▼
                 Google Sheets: «Транзакции» · «Правила» · «Сводка» (+ диаграмма)
```

Сервер не нужен, всё бесплатно, данные лежат только в твоём Google Drive.

---

## 1. Google-таблица и скрипт (≈5 минут)

1. Создай новую таблицу на [sheets.new](https://sheets.new), например «Расходы».
2. **Расширения → Apps Script**. Удали всё в `Code.gs` и вставь содержимое
   [`apps-script/Code.gs`](apps-script/Code.gs). Сохрани (💾).
3. В выпадающем списке функций рядом с кнопкой **Выполнить** выбери **`setup`**
   (не `doPost`!) → **Выполнить**. Разреши доступ
   (Google предупредит, что приложение «не проверено»: *Дополнительно → Перейти…*).
   Делай это **на компьютере**; если окно разрешений уводит не туда, попробуй окно инкогнито с одним аккаунтом.
4. Открой **Журнал выполнения** и скопируй **токен** из строки
   `Токен для Команды на iPhone: …`
   (потом его можно посмотреть в таблице: меню **Расходы → Показать токен**).

   > Если скрипт создан не из таблицы, а напрямую на script.google.com, `setup` сам создаст
   > таблицу «Расходы» и напишет ссылку на неё в журнале.
5. **Развертывание → Новое развертывание** → тип **Веб-приложение**:
   - *Выполнять от имени:* **Я**
   - *У кого есть доступ:* **Все**

   Нажми **Развернуть** и скопируй **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).

> Если позже меняешь код, выбери **Развертывание → Управление развертываниями → ✏️ → Версия: новая**,
> тогда URL останется прежним.

## 2. Автоматизация на iPhone (≈3 минуты)

**Команды → Автоматизация → «+» → «Транзакция»**

1. **Карты:** отметь карты MBank, O!Bank, Simbank (все, что есть в Wallet).
2. Остальное (категории продавцов и т. п.) оставь как есть.
3. Выбери **«Запускать немедленно»** и выключи «Уведомлять о запуске», если не нужно. → **Далее**.
4. **Новая пустая команда**, добавь действие **«Получить содержимое URL»**:
   - URL: *URL веб-приложения из шага 1.5*
   - Нажми **›** → **Метод:** `POST`, **Тело запроса:** `JSON`
   - Добавь поля (тип **Текст**):

     | Ключ       | Значение                                                  |
     |------------|-----------------------------------------------------------|
     | `token`    | *токен из шага 1.4*                                       |
     | `amount`   | переменная **Входные данные команды → Сумма**             |
     | `merchant` | переменная **Входные данные команды → Продавец**          |
     | `card`     | переменная **Входные данные команды → Карта или пропуск** |

     (Нажми на поле значения → «Выбрать переменную» → **Входные данные команды**,
     затем ещё раз нажми на неё и выбери нужное свойство. В разных версиях iOS
     названия свойств могут немного отличаться, например *Amount / Merchant / Card or Pass*.)
5. *(По желанию)* добавь **«Получить значение словаря»** → ключ `message` из
   «Содержимое URL» и **«Показать уведомление»** с этим значением. После каждой оплаты
   будет всплывать `160 KGS · Apteka Elbrus → Здоровье`.

Готово. Заплати любой картой через Apple Pay, и через пару секунд в листе «Транзакции» появится строка.

## 3. QR-оплаты и переводы: скрин → Claude → таблица

Автоматизация «Транзакция» ловит **только оплаты Apple Pay** (приложил телефон или часы к терминалу).
Оплаты по **QR** и **переводы** в приложениях MBank / O!Bank / Simbank она не видит.
Для них есть команда «Скрин расхода»: открыл чек в приложении банка, **дважды стукнул по задней крышке**
iPhone, и Claude сам прочитал сумму, получателя и дату, а в таблице появилась строка.
**Скриншот не сохраняется в «Фото»**: команда делает его в памяти и сразу отправляет.

### 3.1. API-ключ Claude (один раз)

1. Зайди на [console.anthropic.com](https://console.anthropic.com) → **Billing**: пополни баланс
   (минимум $5, этого хватит на сотни чеков: один скрин стоит ≈ 1–2 цента).
2. **API Keys → Create Key**, скопируй ключ `sk-ant-…`.
3. В Apps Script: **⚙️ Project Settings → Script Properties → Add script property**:
   - Property: `ANTHROPIC_API_KEY`
   - Value: *твой ключ*

   → **Save**.
4. Обнови код `Code.gs` из репозитория и сделай **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
   (URL останется прежним).

### 3.2. Команда «Скрин расхода» (iPhone)

**Shortcuts → «+»** (новая команда), назови «Скрин расхода», добавь действия по порядку:

1. **Take Screenshot**
2. **Resize Image**: Width `1000` (меньше картинка, дешевле и быстрее)
3. **Convert Image**: to **JPEG**
4. **Base64 Encode**: нажми **›** → **Line Breaks: None**
5. **Get Contents of URL**: URL веб-приложения, **›** → Method `POST`, Request Body `JSON`, поля (Text):

   | Key | Value |
   |-----|-------|
   | `token` | токен |
   | `image` | переменная **Base64 Encoded** |
   | `source` | `screenshot` |

6. **Get Dictionary Value**: `Value` for `message` in `Contents of URL`
7. **Show Notification**: переменная **Dictionary Value**

### 3.3. Повесить на двойной тап по крышке

**Settings → Accessibility → Touch → Back Tap → Double Tap → «Скрин расхода»**.
(На iPhone 15 Pro и новее можно ещё повесить на **кнопку действия**: Settings → Action Button → Shortcut.)

Теперь после оплаты по QR или перевода, пока на экране чек: **тук-тук** → через 3–5 секунд уведомление
`350 KGS · ИП Асанов → Кафе и еда`.

**Что делает Claude:**
- **оплата / перевод другому человеку** → записывает как расход;
- **поступление, входящий перевод, перевод между своими счетами** → не записывает и пишет почему;
- **нет операции на экране** → «Не нашёл на картинке операцию»;
- категорию сначала ищет по твоим **Правилам**; если магазина там нет, подставляет вариант Claude.

**Если хочешь делиться картинкой, а не стучать:** в настройках команды (ⓘ) включи **Show in Share Sheet**
(тип: Images) и замени первое действие *Take Screenshot* на переменную **Shortcut Input**.
Тогда: «Поделиться» чеком из приложения банка или скрином → «Скрин расхода».
Сделанный вручную скриншот iOS сохранит в «Фото». Чтобы он не сохранялся, после «Поделиться»
нажми **Готово → Удалить снимок экрана**.

### 3.4. Совсем вручную (наличные и т. п.)

Команда **«Расход»**: **Ask for Input** (Number, «Сумма?») → **Ask for Input** (Text, «Где?») →
**Get Contents of URL** с полями `token`, `amount` = *Ввод 1*, `merchant` = *Ввод 2*, `source` = `manual`
(можно добавить `category` через **Choose from Menu**).

## 4. Таблица

| Лист | Что там |
|------|---------|
| **Сводка** | траты этого месяца по категориям (+ круговая диаграмма), топ-15 магазинов, итоги по месяцам, сумма за месяц |
| **Транзакции** | все операции. Категорию можно исправить руками прямо в ячейке |
| **Правила** | «если в названии магазина есть *X* → категория *Y*». Первое совпадение побеждает. Работает и с именами людей: `алтынбек → Семья` |
| **Настройки** | максимальная цена проезда: QR-оплата **частному лицу** до этой суммы считается «Транспортом» (маршрутки). По умолчанию 50 |

**Категория «Не учитывать».** Строка остаётся в таблице, но не попадает в сводку. Используй её для переводов
себе и родным: добавь в «Правила» строку `имя → Не учитывать`. Переводы между своими счетами Claude пропускает сам.

**Приоритет категорий:** твои «Правила» → правило проезда (QR человеку ≤ порога) → вариант Claude → «Без категории».

Меню **Расходы** в таблице:
- **Пересчитать «Без категории» по правилам.** Добавил новое правило, нажал, и старые операции разнеслись.
- **Пересчитать ВСЕ категории.** Переразмечает всё заново (ручные правки тоже перезапишутся).
- **Пересобрать сводку.**

Смотреть с телефона удобно в приложении Google Sheets: лист «Сводка».

## Формат запроса (для отладки)

```bash
curl -L -X POST 'https://script.google.com/macros/s/…/exec' \
  -H 'Content-Type: application/json' \
  -d '{"token":"…","amount":"KGS 160,00","merchant":"Apteka Elbrus  Bishkek, Bishkek","card":"MBank"}'
```

| Поле | Обяз. | Пример | Примечание |
|------|-------|--------|------------|
| `token` | да | `a1b2…` | из `setup()` |
| `amount` | да | `KGS 160,00`, `3 141,1 KGS`, `160` | понимает пробелы, запятые, коды валют |
| `merchant` | нет | `Globus Express  Bishkek, Bishkek` | город в конце и префикс `MD00` обрезаются |
| `card` | нет | `MBank` | |
| `currency` | нет | `USD` | по умолчанию из `amount`, иначе `KGS` |
| `category` | нет | `Такси` | если не передано, берётся из правил |
| `source` | нет | `manual` | по умолчанию `apple-pay` |
| `date` | нет | `2026-09-28T16:38:00+06:00` | по умолчанию время получения |
| `image` | вместо `amount` | base64 JPEG/PNG/PDF | распознаётся через Claude, нужен `ANTHROPIC_API_KEY` |

Повтор той же суммы в том же магазине в пределах 2 минут считается дублем и не записывается.
